# Astro project : La Taverne aux Livres

## Project Structure

```text
/
├── public/
│   └── favicon.svg
├── src
│   ├── assets
│   │   └── astro.svg
│   ├── components
│   ├── layouts
│   └── pages
│       └── index.astro => home page
└── package.json
```

## Start this project

Make sure a recent version of Node is installed on your machine.

1. Install dependencies with `npm install`.
2. To start projet for local development, run `npm run dev` and go to `localhost:4321`.
3. To build your production site to `./dist/`, run `npm run build`.
